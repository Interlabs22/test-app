# Матчи тура: данные и фильтрация

## Цель

Безопасно преобразовать ответ API в модель для интерфейса и определить правила отображения статусов.

## Требования

- Ответ API состоит из номера тура и массива матчей.
- Обязательны идентификатор матча, статус и названия двух команд.
- Счёт и дата начала могут отсутствовать.
- Некорректный или неизвестный ответ API считается ошибкой загрузки и не попадает в UI.
- Дата в UTC форматируется через `Intl.DateTimeFormat` в часовом поясе устройства.
- При отсутствии даты выводится «Время не назначено».

## Статусы и фильтры

| Статус API | Текст в UI | Фильтр |
| --- | --- | --- |
| `scheduled` | Запланирован | Предстоящие |
| `finished` | Завершён | Завершённые |
| `live` | Идёт, N-я минута | Все |
| `postponed` | Перенесён | Все |

Матчи со статусами `live` и `postponed` остаются только во вкладке «Все»: они уже не являются предстоящими, но ещё не завершены. Если минуту текущего матча сервер не передал, статус отображается как «Идёт».

## Проверка готовности

Все восемь матчей из `data/matches.json` проходят валидацию. Ничья `0:0`, отсутствие счёта, текущий матч и перенесённый матч без даты отображаются без потери данных.
