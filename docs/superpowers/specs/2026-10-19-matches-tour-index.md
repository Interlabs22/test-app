# Матчи тура: индекс спецификаций

## Общие ограничения

- Использовать Expo SDK 57, React Native и TypeScript.
- Не добавлять нативные модули: приложение должно запускаться и в Expo Go.
- Валидировать ответ API через `zod` до использования данных в UI.
- Не реализовывать дополнительные функции, кроме небольшой проверки фильтрации, если позволит время.
- Не менять `MATCHES_URL` в рамках реализации экрана.

## Порядок выполнения

1. `2026-10-19-matches-data-and-filters.md`
2. `2026-10-19-matches-favorites.md`
3. `2026-10-19-matches-updated-ago.md`
4. `2026-10-19-matches-screen.md`

## Внешняя предпосылка

`MATCHES_URL` содержит шаблонные `OWNER/REPO`, поэтому успешная загрузка из сети потребует доступного публичного raw-URL. Реализация должна корректно обработать недоступный адрес; решение о замене шаблона на URL опубликованной копии репозитория остаётся за владельцем задания.
