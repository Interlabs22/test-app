# Матчи тура: экран

## Цель

Реализовать экран списка матчей с загрузкой, фильтрами, обновлением и избранным.

## Требования

- При первой загрузке показывается индикатор.
- При ошибке первой загрузки показываются понятное сообщение и кнопка «Повторить».
- При успешном пустом ответе показывается пустой экран.
- При успешной загрузке показываются фильтры «Все», «Предстоящие», «Завершённые», список карточек и кнопка «Обновить».
- В карточке есть названия хозяев и гостей, счёт при наличии, локальные дата и время начала, русский статус и кнопка избранного.
- Повторная неудачная загрузка не удаляет уже показанный список: ошибка сообщается рядом с существующими данными.
- Время последней успешной загрузки передаётся в `UpdatedAgo`; неуспешный запрос его не меняет.

## Проверка готовности

Экран показывает все обязательные состояния и корректно обновляет данные по кнопке «Обновить».
