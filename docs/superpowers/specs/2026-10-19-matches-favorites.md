# Матчи тура: избранное

## Цель

Исправить звёздочку избранного так, чтобы каждое нажатие меняло только выбранный матч.

## Требования

- Избранное хранится в памяти как список идентификаторов матчей.
- Проверка принадлежности использует явную проверку наличия идентификатора, а не значение индекса.
- Добавление и удаление создают новый массив, не меняя предыдущее состояние.
- Обновление использует актуальное состояние React, а не замкнутое значение из прошлого рендера.
- Кнопка показывает заполненную звезду только для избранного матча.

## Проверка готовности

Первый матч можно добавить и удалить из избранного; состояние остальных карточек не меняется.
