## Как я использовал ИИ

Для работы с задачей настроены локальные agent skills в `.agents/`; их состав и источники зафиксированы в `skills-lock.json`. Подключены инструкции для React Native/Expo, системного поиска причин багов, планирования, проверки и code review.

ИИ используется как помощник для анализа и реализации; результаты будут проверены запуском приложения, typecheck и ручной проверкой сценариев перед сдачей.
