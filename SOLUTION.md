## Решения

- В «Предстоящие» попадают только матчи со статусом `scheduled`, в «Завершённые» — только `finished`. Матчи `live` и `postponed` остаются в «Все»: они не соответствуют ни одному из двух фильтров и не должны маскироваться под будущие или завершённые.
- Время начала берётся из серверного поля `startsAt` и формируется через `Intl.DateTimeFormat`, поэтому отображается в часовом поясе устройства. Для отсутствующей даты выводится «Время не назначено».
- Счёт `0 : 0` отображается как настоящий счёт, а не скрывается как ложное значение. Для матчей без счёта счёт не рендерится.
- Для матча в прямом эфире выводится минута, если сервер её прислал; для перенесённого матча выводится отдельный русский статус.
- Карточки различаются цветом левой границы и статуса: завершённые — зелёные, текущие — красные, перенесённые — оранжевые, запланированные — серые. При пустом выбранном фильтре выводится отдельное понятное сообщение.

## Баги из части 2

1. Звёздочки: проверка через `Boolean(indexOf(id))` ошибочно считала первый элемент массива невыбранным, потому что его индекс равен нулю. Кроме того, массив изменялся на месте, и React мог не заметить изменение состояния. Проверка заменена на `includes`, а при добавлении и удалении создаётся новый массив.
2. «Обновлено N сек назад»: таймер использовал устаревшее значение времени и не перезапускался при новом обновлении данных. Теперь компонент хранит текущее время в состоянии, очищает интервал при размонтировании и заново запускает его при изменении `since`.
